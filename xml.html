Data Validation using XML

Modern web applications exchange and organize structured data. XML (eXtensible Markup Language) is one of the standard formats used to represent and validate data.

✔ Valid XML Example

<user>
    <name>Meghana</name>
    <email>meghana@example.com</email>
</user>

❌ Invalid XML Example

<user>
    <name>Meghana</email>
</user>

The second example is invalid because the opening and closing tags do not match. XML requires every opening tag to have the correct closing tag.
